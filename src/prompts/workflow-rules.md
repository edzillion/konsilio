# Workflow Rules

Single-run constitution for the council analysis workflow.

## Quality Standards

- Every finding must be actionable and specific
- Generic advice without concrete steps is rejected
- All recommendations must reference the stated tech stack
- Severity must reflect actual impact, not theoretical worst-case

## Output Requirements

- JSON output must be valid and parseable
- No markdown formatting in JSON responses
- Each finding needs a unique, descriptive ID
- Mitigations must include implementation guidance

## Expert Conduct

- Stay within your assigned expertise domain
- Do not duplicate findings from other experts
- Acknowledge uncertainty when evidence is insufficient
- Prioritize findings by actual risk to the project
